Edit Articles

Anyone can add, correct, revise, or improve the contents of any articles. Wiki articles are text-based but support basic formatting features such as bold text, italic text, tables, and even inserting hyperlinks and pictures into the article. This is done through a syntax called Markdown. List of supported Markdown syntax are described in the Markdown Cheat Sheet.

The following describes how to edit an article:

  1. Navigate to the article you want to edit (in this example, the article Article 1.3 will be edited). Click on the Article menu, then select the Edit option.

  2. You will see the Edit page. You are free to change the Title of the article and include a brief summary or explanation of changes in the article in the Summary field. The most important field is the Contents field because this is where you will make the changes to the article contents.

  3. As previously mentioned, Wiki supports the Markdown syntax that allows you to apply some basic formatting to your text. Fig. 3 is a demo of the article contents, applied with some Markdown syntax. Click on the Save button (Fig. 2) to save your changes, and Fig. 4 is the result of Fig. 3.

    List of supported Markdown syntax are described in the Markdown Cheat Sheet.

  4. Insert Table of Contents. If your article contains many section headers, you might want to consider adding a Table of Contents that will list all the section headers in the text and allow quick navigation to any section when the user clicks on the section header name.

    Pick a place in the article where you like the Table of Contents to be added. A good location is the top of the article, then type in [TOC] (including the square brackets). When saved, the article will have a Table of Contents added.
