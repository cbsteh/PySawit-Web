Delete Weather File

Deleting a weather file removes the file from your Weather Files listing page. Note that file deletion is permanent and cannot be recovered.

The following describes how to delete a weather file:

  1. At your Weather Files page, click on the delete link under the weather file you wish to delete.

  2. You will be asked to confirm your deletion request. Click on the Delete button to continue, else the Cancel button to abort the request.
