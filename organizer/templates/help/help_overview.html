How to use

Your activities in PySawit Web will typically involve six steps:

  • 1. Log in

    Log in using your username and password (both case-sensitive).

  • 2. Weather data

    All modeling work require daily weather data of a given oil palm site. PySawit Web is able to use weather data from four sources:

    1. use your weather data,
    2. use one of the weather files from the repository,
    3. use the NASA POWER weather data, or
    4. use the model's daily weather generator.

  • 3. Model input

    Create or use an existing Run file. Enter the values of the model parameters you wish to change, such as the site latitude, initial tree part weights, and duration of the simulation run. Default values are given for all model parameters.

  • 4. Run the model

    Start the model run. As simulation runs can be lengthy, a request to run your model is created by putting your request in a queue. Once it is your turn, your model will be run (in the background) until completion.

  • 5. Simulation results

    Simulation results (model output) can be viewed once the model run is completed. Simulation results can be:

    1. viewed as a tabular form, or
    2. plotted as a series of pre-defined charts.

      Customized plotting is also available where you can plot your chosen model parameters.

  • 6. Results analysis and interpretation

    Simulation results can be further exported:

    1. as a text file, or
    2. as a new Excel file.

    for more detailed analysis and interpretation by using another software such as Excel.

      You may also upload an existing Excel file so that the model results are written to it, updating your file with the latest results.
