Import into Excel

Weather text files (.txt) that are downloaded can be imported in Excel. The values in weather text files are comma-delimited, meaning that the values are separated by commas.

To import a weather text file into Excel, please do the following:

  1. Launch Excel and go to the Open menu. Click on Browse.
  2. Find the weather file you wish to import, then click on the Open button to select it.
  3. You will be presented with a Text Import Wizard dialog. Ensure the Delimited radio button is selected, then click on the Next button.
  4. Check/tick only the Comma and Space delimiters and uncheck/untick the others. Finally, click the Finish button to start the weather file import.
  5. Once the file import is completed, the weather data will appear in one of the worksheets. Cells A4:E4 denote the daily weather parameters, where doy, tmin, tmax, wind and rain denote the column data for day of year, minimum air temperature (°C), maximum air temperature (°C), wind speed (m s-1), and rain (mm), respectively. The asterisk * before doy indicates that doy is the key, used by PySawit Web to retrieve the daily weather properties for a given day of year. PySawit Web requires all weather data files to prefix the doy field with an asterisk *. Rows 1 to 3 are comment lines and can be deleted, if needed.
  6. Alternatively, you could also import the weather data into Excel by the copying-and-pasting method. Open your weather data text file with any text editor, and copy all the data into the clipboard.
  7. Choose a cell location in an Excel worksheet you wish to copy and paste the clipboard contents. In this example, the weather data (copied into the clipboard) will be pasted in cell A1.
  8. After pasting into Excel, the data needs to be properly formatted, so that each value occupy a separate cell (like in Fig. 5).
  9. Click on column A to quickly select all the data that have been previously pasted.
  10. After selection, choose the Data from the Excel Ribbon, then click on the Text to columns option. This will trigger the Text Import Wizard dialog to appear. Follow the instructions as shown above in Fig. 3 and 4 to complete the weather data import, and the result should be like Fig. 5.
