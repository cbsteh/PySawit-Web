Steps to modify weather data

If you wish to change the data in a weather file, you need to download the weather file to your local computer first, then make the changes (using Excel, for instance), and finally re-upload the modified weather file into PySawit Web. PySawit Web does not support in situ changes to weather data.

  • Download

    Download the weather file as a plain text file or Excel file.

    How to download?

  • Modify

    Working on the downloaded file, modify the weather data. You can use Excel to simplify the modification process.

    How to import a weather file into Excel?

  • Upload

    Save the modified weather file, and upload this file into PySawit Web. If you are using Excel to modify your weather file, you will have to save the file as a CSV file before uploading.
