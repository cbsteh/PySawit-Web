Step 2/3. Create the Weather File

Your weather data must be prepared in a plain text file, following the format or specifications as described in Step 1.

The following steps describe how to prepare your weather file

  1. A recommended method to prepare your weather file is to use Excel to first clean and format your weather data. In this example, columns A, B, C, D, and E are for day of year, min. air temperature, max. air temperature, wind speed, and rain, respectively. Do not forget to prefix * to doy (cell A1).
  2. Now, save the weather data as a CSV (comma-separated values or comma-delimited) text file.
  3. Choose a suitable name for your weather file. In this example, the name is merlimau with a file extension .txt. Enclose the entire filename with double quotes, like this: "merlimau.txt". Without the double quotes, Excel will save the file with the name merlimau.txt.csv. The double quotes prevents Excel from appending .csv to the filename. Now click the Save button.
  4. To verify your new weather file has been correctly formatted, open this file using any text editor, and your weather file should be formatted like that in Fig. 5.
  5. It is recommended to document your weather file by providing details such as the site's name, location, and elevation, height of weather station, and period of weather data. Documentation is done via comment lines. Recall that comment lines always begin at the start of the file, and they must be prefixed with the hash symbol #.
  6. A common problem to look out for is the presence of one or more extraneous commas at the end of the file lines. These extraneous commas will appear when some cells in Excel contain only spaces. These spaces are invisible, so these cells appear blank or empty, but Excel treats these cells as non-empty, so includes them as data when you save the file.

    How did these spaces appear in the cells? This often occurs when the Space bar key was accidentally pressed whilst navigating the Excel worksheet or when the Space bar key (instead of the Delete key) was used to delete entire cell contents.

  7. To easily remove these extraneous commas, launch Excel, and open the original weather file that you had used to prepare and save the weather data text file. From the Home ribbon, select the Find & Select option.
  8. You will be presented with a Find and Replace dialog. In the Find what: field, type in a single space, and leave Replace with: field blank. Uncheck (untick) the Match entire cell contents option, then click on the Replace All button. This will remove all cells containing only spaces in the Excel worksheet.
  9. Repeat the steps as shown in Fig. 2 to 4 to save the weather data as a CSV plain text file (but with the file extension .txt). As before, use any text editor to open the weather text file, and the file should look like in Fig. 5, without the extraneous commas.
  10. Your file is now ready to be uploaded into PySawit Web to be used. Please refer to the final Step 3 on help on how to upload your weather text file into PySawit Web.
