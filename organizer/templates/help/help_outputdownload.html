Download Results

You have three options to download the model results to your local computer:

  1. download a comma-separated text file (CSV),
  2. import the results into a new Excel file, then download this file, or
  3. update an existing Excel file

This is how to download the model results:

  1. At the Results page, click on the download link.

  2. As stated earlier, you have three options for download: 1) a plain text file, 2) an Excel file, or 3) update an existing Excel file.

    Downloading the model results in whichever form is very similar to that for downloading weather files. Please refer to the instructions as described here. For Excel files, the model results will be written in a worksheet named annual and daily for annual and daily results, respectively.

    Model results stored in a plain text file can be imported into Excel in the same way you would do for a weather data text file. Again, please refer to the instructions as described here on how to do this.
