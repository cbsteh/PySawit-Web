Edit Weather File Description

Editing refers only to changing the description of a weather file and not about modifying the values of the weather data. If you wish to modify the weather values, please instead refer here.

The following describes how to edit the description of a weather file:

  1. At your Weather Files page, click on the edit link under the weather file you wish to alter its description.

  2. Enter the file description in the Description field. It is recommended to include some brief information about the weather file in the description such as the site name, location, and period of weather data. When done, click on the Save button to keep the changes.
