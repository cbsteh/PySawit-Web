Weather Data Repository

The weather data repository stores several weather files that you can use in your crop simulations.

To select a weather file from the repository:

  1. Go to the Weather Files page, and click on the Upload button.
  2. Then click on the Get from the weather repository panel.
  3. You will see a list of weather files in the repository. This list may change as more files are added later. Choose the desired weather file. In this example, choose the Merlimau weather file by clicking on its name.
  4. When you click on a weather file, its details are added into the Description field. For the Merlimau file, its details are "Merlimau, Melaka; GPS: 2.253213, 102.451753 deg., Elev: 47.13 m, Station: 2 m; 1987/1/1 - 2008/12/31", giving details on the site name, GPS location, elevation, and start and end dates of weather data. You can change this file description, but it is recommended to keep this information as it is. Once ready, click the Upload button (see Fig. 2) to upload the weather file.
  5. Once uploaded, you will be presented with a table showing the weather data. The visual distribution and statistical characteristics of each weather parameter are also displayed.
  6. Upon a successful upload, the Merlimau weather file will now be listed under your Weather Files page. This file is now ready to be used in your crop simulations.
