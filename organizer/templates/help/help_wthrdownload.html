Download Options

All weather files listed in your Weather Files page can be downloaded to your local computer. A weather file can be downloaded as a plain text file or an Excel file. You can also upload your Excel file and have PySawit Web update that file with the weather data.

To download a weather file:

  1. Go to your Weather Files page, and click on the download link under the weather file you wish to download. In this example, the merlimau-87-08.txt is the file of interest and that will be downloaded. Thus, click on its download link.
  2. You will be presented with a Download Weather page where you have three options to download the weather data as: 1) a plain text file, 2) an Excel file, or 3) update an existing Excel file.
  3. Option 1: Plain Text File. Click on the 1. Text File panel (Fig. 2) which will open up the Text File panel. Now click on the Download text file button to begin the download process. The text file will be saved in your browser's default folder. You can use your computer's text editor (such as Notepad in Windows) to view the weather text file. The first three lines of the file, starting with the hash symbol #, are comments and are ignored by PySawit Web; they serve only for documentation purposes. The line immediately after the comment lines, that is the fourth line, lists the column headers, denoting the daily weather parameters, where doy, tmin, tmax, wind and rain denote the column data for day of year, minimum air temperature (°C), maximum air temperature (°C), wind speed (m s-1), and rain (mm), respectively. Finally, the asterisk * before doy indicates that doy is the key, used by PySawit Web to retrieve the daily weather properties for a given day of year. PySawit Web requires all weather data files to prefix the doy field with an asterik *.
  4. Option 2: Excel File. Click on the 2. New Excel File panel (Fig. 2) which will open up the New Excel File panel. Now click on the Download Excel file button to begin the download process. The text file will be saved in your browser's default folder. Open the downloaded file with Excel to view the weather data. Your weather data is saved in the wthr worksheet.
  5. Option 3: Update Excel File. Click on the 3. Updated Excel File panel (Fig. 2) which will open up the Updated Excel File panel. Click on the button (step 1, Fig. 7). Find your Excel file (step 2, Fig. 8) and click on the Open button to select it (step 3, Fig. 8). Now click on the Update button (step 4, Fig. 7) to upload and update your Excel file. Once the update is completed, a copy of your Excel file will be downloaded to your browser's default folder. Your weather data is saved in the wthr worksheet.
  6. And finally ...

    New vs. Update

    What is the difference between downloading the weather data as a new Excel file (option 2) and updating an existing Excel file (option 3)?

    In option 2, a new and empty Excel file will be created. A worksheet named wthr will be created and be populated with the weather data.

    Option 3 allows you to use your existing Excel file like a template to receive only updated or new weather data, while still preserving, if any, the formatings, Excel formulas, or charts you might have. Without option 3, each time you download a weather file, you will have to repeat whatever customizations (e.g., charts, formulas, or formatings) you like to have for the weather data.
