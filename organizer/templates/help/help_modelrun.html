Step 2/2: Model Run

Due to the intensive and repetitive computations. a model run can take several minutes to complete. While this is acceptable on a local computer, a program that takes this long to complete its task on the internet is too long. The server can timeout, causing a premature end to a model run. This server timeout can be a serious problem particularly during heavy web use (for instance, many users simultaneously using PySawit Web to run their simulations).

Consequently, whenever you start a model run, your request is put on a queue or waiting list. In other words, your model simulation may not immediately start, as there could be other model run requests ahead of yours. Once it is your turn, your model run is then started.

How long would you have to wait for your model results? This would depend on the simulation duration as well as web traffic. The longer your simulation run, the longer you would have to wait (e.g., a simulation run of 10 years would end faster than a run of 20 years). Likewise, the more number users simultaneously using PySawit Web could increase your wait time, as there could be many model run requests in the queue.

The following describes starting the model run process:

  1. There are two ways to start a model run. The first is to click the run link below the run file's name. But you need to first ensure the selected run file has the intended model input values before you start the model run.

    The second way to start a model run is via the run file's Edit page. This is the recommended way as you can check all the model parameter values are correct before starting a model run. Click on the Run button at the end of the page. This button will first save your changes to the model input then start the model run.

  2. You will be asked to confirm your run request because, as stated earlier, a model run may take several minutes to complete.

  3. You will be notified that your model run request has been placed in the queue.

  4. A map pin appears next to the run file's name in the Run Files page to indicate that model run is pending. During this time, you will not be allowed to put in another run request for the same run file. Also notice that the run link under the run file name is grayed out.

    The Results page is also unavailable during this waiting period.

  5. Reload the page to check if the model run is completed. PySawit Web does not automatically reload the page or notify you when a model run is completed; you will have to manually reload the page or check back later into PySawit Web.

    When your model run is completed, the map pin (Fig. 5) disappears, and the Results page will now be populated with the model output.
