Step 3/3. Upload the Weather File

Before uploading your weather data text file, please ensure your file was prepared in the format and manner as described in step 1 and step 2. This is to ensure PySawit Web correctly reads in your weather data.

The following steps describe how to upload your weather text file:

  1. At the Weather Files page, click on the Upload button
  2. Click on the Browse button (step 1, Fig. 2) to find and select your weather file you wish to upload into PySawit Web (step 2 and 3, Fig. 3).
  3. Finally, click on the Upload button (step 4, Fig. 2) to upload your selected weather file. PySawit Web will warn you if the uploaded file is of the wrong type (e.g., not a text file), incorrectly formatted, has discontinuous data or missing values, or is too large (i.e., larger than 1 Mb file size). Once uploaded, your file should appear in the Weather Files page.

    Note that no description was given to your newly uploaded weather file. To enter one (or edit a current description), click on the edit link to edit the file description. How to do this is as described here.
