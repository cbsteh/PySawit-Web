PySawit Web v. 2.0

Oil palm growth and yield model

by Christopher Teh Boon Sung, Uni. Putra Malaysia

About

PySawit Web is the graphical user interface (GUI) of the PySawit model. PySawit is the engine that simulates the growth and yield of oil palm under various meteorological, plant physiology, and soil conditions, as well as under various planting densities. Where PySawit is the engine, PySawit Web is the web-based facade that acts to shield users from having to deal directly with PySawit. Via the web browser installed on the users' computers or smartphones, PySawit Web collects from the users the model input and then feeds PySawit the model input to run crop simulations. Model output are then collected by PySawit Web and presented to the users. Users do not need to know Python or any other computer languages or need to install additional software on their computers or phones to use the oil palm model.

PySawit Web is the outcome of the Incentive Grant for Research in Teaching and Learning (GIPP), 2017-19, a grant awarded to Christopher Teh Boon Sung, a lecturer and researcher at Uni. Putra Malaysia. PySawit Web is designed as a research and teaching tool for agriculture researchers and students.

PySawit Web was built using Django and jQuery.
