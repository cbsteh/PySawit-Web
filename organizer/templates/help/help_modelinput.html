Step 1/2: Model Input

Although the oil palm model has over 60 model parameters, you do not have to set the value for each of them. You will only need to set values for model parameters that are specific to your site or modeling conditions and rely on default values for the others. Table 1 lists the model parameters that would often need your input, as their values are dependent on site or modeling conditions.

Table 1. Frequently-changed model parameters

Parameter Units/Range Description
Name of run -- Name of the run file. By default, PySawit Web names run files with the following format: Run-YYMMDD-hhmmss, where YY, MM, and DD are for the year, month, and day, respectively; and hh, mm, and ss are for the hour, minutes, and seconds, respectively (note: time is based on a 24-hr format). For instance, Run-181121-114621 indicates the run file was created on Nov. 21, 2018 at time 11:46:21 (morning). You are, of course, free to change such default names to those more suited for you.
Simulation days days Duration of simulation run (max. 20 years or 7300 days)
Site latitude decimal degrees Latitude of site location
Weather station height m Height of weather station (will be ignored if daily weather is generated/simulated)
Initial day of year 1-365 Day of year for the start of your simulation run (Jan. 1 = 1, ..., Dec. 31 = 365). Note: If you are using a weather file, a simulation run always begins reading the weather from the first year of the weather data set in your weather file. See the note below.
Weather data source -- Choose either 1) weather simulation or 2) weather file as the source of daily weather. If you choose (1), you will need to specify the weather simulation parameters (see below) for air temperature, rain, and wind speed.
Weather simulation parameters -- These parameters are required if you choose to have your daily weather generated (simulated) rather than read from a weather file, as these parameters are highly specific to a site. You require to enter information such as the annual properties for min. and max. air temperature (mean, amplitude of mean, coefficient of variation [CV], amplitude of CV, and mean specific for wet days), the probabilities of dry and wet days, and the distribution shape and scale for wind speed and rain.
Weather filename -- Name of weather file (file must be listed in your Weather Files listing page, or else you will have to upload the desired weather file). This parameter will be ignored if you choose to simulate the daily weather.
Initial tree age days Age of tree (in days) at simulation start
Planting density palms ha-1 No. of palms per hectare
Initial weights (for the various tree parts) kg DM (dry matter) palm-1 You can use the default weights for normal field planting tree age (when palm age is 1 year old).
Initial ambient CO2 µmol mol-1 The concentration of the ambient atmospheric carbon dioxide at the start of simulation. You can have the CO2 level calculated if you enter the year but as a negative value. For instance, if you give -1987, the mean ambient CO2 level for the year 1987 will be calculated.
Initial rooting depth m Depth of the roots at the start of simulation. You can use the default value for normal field planting tree age (when palms are 1 year old).
Any water table? Yes/No Select Yes if there is a presence of a water table, else No. Note that the water table is taken as the saturated soil layer just below the last soil layer.
No. of soil layers 2-6 At least two soil layers are required. The number of soil layers would depend on the soil's heterogenity.
Soil layer properties -- Each soil layer requires information on its soil thickness, initial soil water content (see below), texture (clay and sand), and organic matter level. If you have chosen 3 soil layers, then information for each of these 3 soil layers must be provided.
Initial water content m3 m-3 Volumetric soil water content for a given soil layer. The value should range between 0 and 1. Negative values between -3 and -1 have special meanings, where -3 indicates permanent wilting point, -2 is for field capacity, and -1 is for saturation. Linear interpolation is also supported, so that -1.5 indicates a soil moisture level halfway between saturation (-1) and field capacity (-2).

The following describes how to enter the model input:

  1. Before you can run any crop simulations, you need to have at least one run file. A run file is a simply a file containing your model input for all crop simulations. Go to your Run Files page to see your list of run files. Click on the name of a file to open and edit the file. Or you can click on the New button to create a new run file.

  2. You will be presented with the run file's Edit page, where you will enter the values for several model parameters. As stated earlier, the oil palm model contains over 60 model parameters, so these parameters are grouped under several panels to make navigation and data entry easier.

    Click on a panel name (or icon) to toggle between expand (open) and collapse (close). Some of these panels have one or more sub-panels (nested panels), and these sub-panels can also toggle between expand and collapse.

    To quickly expand all panels, click on the expand all round button, and to quickly collapse all panels, click instead on the collapse all round button. Clicking on the cancel round button or on the Cancel button will return you to the Run Files page, without saving the changes to the model input.

  3. At the far right end of each panel is a slider (Fig. 2) to toggle between expanding and collapsing a navigator side menu (Fig. 3). The purpose of this side menu is to make navigation easier so you can see a list of all model parameters and quickly navigate to any of them. Clicking on any model parameter on the side menu will expand the necessary panels and bring into view the selected parameter.

    There are three ways to collapse the side menu: 1) clicking on the slider (at the far right end of any panel), 2) clicking on the close button on the upper right corner of the side menu, or 3) double-clicking on the side menu.

  4. Some of the model parameters under the Meteorology panel will almost certainly need to be changed, such as the Site latitude, Weather station height, Initial day of year, Weather data source, and Weather filename. See Table 1 for their description.

  5. If your simulation begins when the palm age is 1 year old (365 days) and at field planting, then the default values for many model parameters can be used. Model parameters under the Crop panel will often require no change unless your simulations are about various planting densities, thinning, or thinning age.

  6. Soil parameters under the Soil Water would often require your input as they are dependent on your site or modeling conditions. Here, you need to specify if there is a presence of ground water (water table) and the number of soil layers (minimum is 2 and maximum is 6). Having soil layers is a way to capture soil heterogenity so that each soil layer has a rather uniform set of characteristics.

  7. You will also often need to specify the characteristics of each soil layer. For instance, if you had specified three soil layers (see Fig. 6), then the characteristics of each of these three soil layers must be specified (the characteristics of the 4th to 6th soil layers will be ignored in this case). See Table 1 for the description of the soil layer properties.

  8. At any time, you can click on the Save button (Fig. 2) to save your changes. Once model input is completed, you can click on the Run button to start the model simulation. Clicking on this button also saves your changes to the model input before starting the simulation.

Note on the weather data in weather files

A weather file may contain weather data for one or more years. PySawit Web does not require the year to be included in the weather files because it assumes that all simulation runs will use the weather data in the first year of the data set.

For instance, if your simulation date starts on Jan. 15, 1988, your weather file must start with the weather data for 1988 (also enter 15 as the initial day of year; see Table 1 above). Since your run begins on Jan. 15, PySawit Web will read the the weather data starting from the 15th day of the first year (implicitly assumed as the year 1988) in the weather file.

Likewise, if your simulation date starts instead on Jan. 15, 1990, your weather file must modified to start with the weather data for 1990. In other words, it is assumed a simulation run always uses the first year weather data set in your weather file.

If you using the repository weather file or downloading the weather data from the NASA POWER site, you have to ensure (either by modifying the weather file or specifying the correct starting year before you download from NASA) that the first year weather data set in the files is for the starting year of your simulation run.
