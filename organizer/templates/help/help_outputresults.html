Simulation Results

When a model run is completed, the model results are stored and can be accessed from your Run Files page. Model results can be viewed in a table or chart form, and they can also be downloaded to your local computer. Note that whenever you run your model again, the previous model results will be cleared for the new model run output.

The following describes how to access your model results:

  1. Simulation results from your latest model run can be accessed from your Run Files listing page. Under the selected run file, click on the results link.

    Please note that each run file has its own set of model results.

  2. Your Results page presents the simulation results as two groups: Annual and Daily. The annual results are a summary of the daily model results.

  3. Click on the Annual results link (Fig. 2) to view the annual model results in a table or grid form.

  4. Click on the charts link under the Annual results (Fig. 2) to plot the annual model results in a series of pre-defined charts. These charts are categorized under different panels, and these panels are expandable. Click on any panel to toggle between expand and collapse to reveal or hide these charts, respectively.

  5. You may choose which parameters to plot in a chart. For custom plots, click on the plot link under the Annual results (Fig. 2). You will be presented with a page to select at least a pair of model parameters to plot. For the x-axis, choose one parameter (Step 1), and for the y-axis, you can select up to six parameters (Step 2). Choose if you wish to have a scatter or line chart (Step 3). When ready, click on the Plot button to plot the chart (Step 4). Note that you can clear all the y-axis selections by clicking on the clear selections button.

  6. As an example, Fig 8 and 9 show that actual_T (actual transpiration) was plotted against LAI (leaf area index) as a scatter chart.

  7. You can access the daily model results in the same manner as described earlier in Fig. 2 to 9 except you will instead click on the Daily results name or its links under it (Fig. 2).

  8. Technically, Raw input (Fig. 2) is not a model output but instead a model input file in JSON format. PySawit Web reads in your model input and converts them into this JSON-format text file for the oil palm model. You will normally have no use of this file, but an option to view (and download) this file is provided for debugging or checking purposes for specialists. Click on the Raw input name to view the JSON-format form of the model input. Clicking on the download button will download the text file into your local computer.
